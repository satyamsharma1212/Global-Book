# Global Book Publishing

A premium, responsive Next.js website for Global Book Publishing.

## Stack

- Next.js App Router
- React + TypeScript
- CSS (no Tailwind dependency)
- Lucide React icons
- Responsive/mobile-first layout

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## WhatsApp setup

Copy `.env.example` to `.env.local`:

```env
NEXT_PUBLIC_WHATSAPP_NUMBER=91XXXXXXXXXX
```

Replace the placeholder with the company's verified WhatsApp number in international format, without `+` or spaces.

Then restart the development server.

## Important before launch

Replace any placeholder contact information with verified company details.

The website intentionally avoids promising guaranteed income, acceptance, delivery time, or payment. Add those claims only when they are supported by the company's official terms.

## Production

```bash
npm run build
npm start
```
